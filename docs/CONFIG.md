# 用自己的图片

0.2.2 附带 128 张咖波图片，第一次启动自动导入本地图库，按 F10 即可选用；更新时按图片内容去重，不更改已保存的选图、帧号、热点和大小。

推荐直接在游戏里操作：主菜单点击“光标图库”，或按 F10；点击“导入图片…”可一次选择多张 PNG/APNG、WebP、GIF，再选择普通、画笔或橡皮擦模式。左侧点选预览，点击预览设置作用点，点击“保存并应用”。顶部开关可以关闭后重新启用，F9 关闭后也可在这里恢复。

选中动态图后，用“默认帧”的帧号或滑条逐帧查看，找到喜欢的一帧后保存。界面帧号从 1 开始，普通、画笔、橡皮擦分别记住自己的选择；重新打开和重启游戏会恢复。静态图禁用选帧。预览期间不会改变当前配置，也不会改动原动态图。

平时显示选定的默认帧，按住右键从原动画开头循环播放，松开恢复选定帧。左键保持静态，不写入配置。右键仍传递给原游戏，在地图可能同时触发原本的临时绘图或擦除模式；各模式可选不同图片。

第一次加载后，在游戏日志查找 `[CustomCursorLoader] 配置目录`。Windows 默认目录为 `%APPDATA%/SlayTheSpire2/CustomCursorLoader/`，与游戏安装位置无关，也不会被 Steam 工坊更新覆盖。

将你有权使用的咖波图片放进该目录下的 `cursors/咖波.png`，修改 `config.json`：

```json
{
  "enabled": true,
  "cursorImage": "cursors/咖波.png",
  "scale": 1.0,
  "opacity": 1.0,
  "hotspotX": 8,
  "hotspotY": 6
}
```

保存后约 1 秒更新。覆盖了 PNG 但没有改配置时，按 F8 重新读取图片。随附咖波图片已在图库内，也可继续添加自己的图片。

支持带或不带 BOM 的 UTF-8 配置。图库导入的文件位于同目录的 gallery/，原文件保持不变；相同内容自动去重。自动缩放和预览不裁掉图片里的文字，建议先选用已经处理好的无字素材。

| 字段 | 规则 |
|---|---|
| enabled | true 启用，false 恢复游戏原版普通、画笔和橡皮擦光标 |
| cursorImage | 相对配置目录的路径，或本地绝对路径；中文、空格、大小写 PNG 扩展名均支持 |
| cursorIdleFrame | 普通光标的默认帧，JSON 从 0 开始；不写时为 0，即界面的第 1 帧 |
| scale | 缩放倍率，范围 1/2048–256；输出仍不超过 256×256，非有限数值用 1 |
| opacity | 原图 Alpha 乘以此值，范围 0–1；0 完全透明，可按 F9 恢复 |
| hotspotX / hotspotY | 原始 PNG 左上角为 (0,0)，单位为源图像素；缩放时一起换算并限制在图内 |
| drawCursorImage / eraseCursorImage | 可选地图画笔、橡皮擦 PNG 路径；空字符串沿用该模式的原版光标 |
| drawIdleFrame / eraseIdleFrame | 画笔、橡皮擦的默认帧，JSON 从 0 开始；三种模式独立保存 |
| drawHotspotX / drawHotspotY | 画笔 PNG 的源图热点坐标 |
| eraseHotspotX / eraseHotspotY | 橡皮擦 PNG 的源图热点坐标 |

地图图片的最长边会与普通光标一致，保持各自比例、独立热点及全局 opacity。点击地图画笔或橡皮擦按钮，以及使用原游戏临时画图/擦除操作时，自动切换对应光标。可在现有 JSON 中加入如下字段，热点应按自己的图片调整：

```json
{
  "drawCursorImage": "cursors/画笔.png",
  "drawHotspotX": 16,
  "drawHotspotY": 24,
  "eraseCursorImage": "cursors/橡皮擦.png",
  "eraseHotspotX": 18,
  "eraseHotspotY": 26
}
```

地图图片加载失败时，仅该模式回退原版；修复后按 F8。F9 会同时恢复普通、地图画笔与橡皮擦光标。

不展开 `~` 或 `%环境变量%`，不支持 URL、res://。绝对 Windows 路径在 JSON 中写成 `"D:/我的光标/咖波.png"`，或把反斜杠写成 `\\`。文件按实际内容识别 PNG/APNG、WebP、GIF，扩展名误写的 WebP 也能读取；导入时会使用正确扩展名。图片不会作为脚本执行。

动画最多 120 帧，源画布每边最多 2048，画布像素×帧数×4 不超过 128 MiB，文件最多 8 MiB。帧延时沿用原文件，低于 20 毫秒按 20 毫秒播放；每次按住从原动画首帧开始循环，松开回到选定默认帧。默认帧负数取 0，超过实际帧数取最后一帧；选择新图片时默认重置为首帧。所有帧使用同一画布、显示大小和作用点；透明画布的初始化及清除使用透明黑。GIF 解码依赖 Windows 自带 GDI+，无需另装库。

## 大小和分辨率

Ctrl＋Alt＋＝ 放大，Ctrl＋Alt＋－ 缩小：使用主键盘的等号和减号键，不需要 Shift。每按一次把当前最长边增减 8 像素，保持比例和同一个源图热点，并自动写回 scale。放大上限 256、缩小下限 16；原先小于 16 的光标不会因为按缩小键反而变大。按住不连续触发。

例如现在的 64×64 咖波，按一次放大变成 72×72，按一次缩小变成 56×56。大源图也可缩小到 16，不再受旧版 0.05 最小倍率限制。已配置的自定义画笔与橡皮擦会跟随普通光标的最长边缩放。关闭或普通光标加载失败时快捷键不自动启用光标。

32×32 原图的倍率 0.5、1、1.5、2、3 分别得到 16、32、48、64、96 像素的光标。输出最大 256×256；超过时会等比例缩小，日志显示实际尺寸。非正方形图片保留比例，边长按像素四舍五入，极窄边最小 1 像素。

建议使用透明 RGBA PNG、32–128 像素的成品尺寸。调整大小采用 Lanczos 重采样；像素画最好按最终显示尺寸制作，并使用 scale=1，避免重采样模糊。源图任一边最多 2048 像素，文件最多 8 MiB；源图过大直接拒绝，保护解码内存。Godot 官方建议硬件光标不超过 128×128，当前 Windows API 上限 256×256。

光标使用硬件窗口像素，不随游戏的 1920×1080 内容缩放一起放大。更换分辨率不需要调整热点；系统 DPI、全屏切换的视觉表现仍需按测试清单确认。

## 热点示例

假设 64×64 咖波 PNG 中小爪子位于源图 (10,14)，设置 hotspotX=10、hotspotY=14。当 scale=0.5 时实际热点是 (5,7)，仍对应小爪子。Mod 不移动真实鼠标、不改点击坐标。地图两张图片分别使用自己的热点；Help 检查光标和其他 OverrideCursor 特殊图片保持原版。

## 错误与恢复

缺失、损坏、无法读取、超大 PNG 或非法配置会恢复原版，并在日志记录原因。配置错误不会被自动覆盖。修正配置后会重新加载；仅修正图片内容时按 F8。

F9 先立即恢复，再保存 enabled=false；保存失败也保留本次会话的原版光标。F9 保存时把原配置复制到 config.json.bak，因此即使原配置损坏，也可以查看备份。重新启用可用图库顶部开关，或把 enabled 改为 true。

也可将多张本地图片放入 cursors/ 或 gallery/，打开图库后点击“刷新图库”。该目录属于玩家用户数据，不随工坊更新覆盖。
