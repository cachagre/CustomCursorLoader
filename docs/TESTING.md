test-results/v0.2.2-core-tests.txt 和 v0.2.2-window-runtime.txt 保存当前记录；BUILD_REPORT.md 保存版本哈希、部署和跨进程验证。0.2.0 和此前版本的测试记录保留，不将历史结果算作新版本实测。

运行脚本先复制游戏到独立目录，禁用 Steam，检查 user:// 重定向，只修改新测试目录；测试驱动没有安装到玩家正常游戏。地图使用真实资源和原方法下的局部状态，不连接网络或模拟完整战斗。窗口检查可以确认界面布局、源图热点换算和引擎状态，仍不能证明实际手感、硬件光标是否闪烁、DPI 或全屏表现。

没有使用操作系统全局键盘/鼠标来驱动游戏。headless 不支持真实鼠标隐藏，相关检查在 Windows 窗口运行中完成。退出阶段的游戏 RID/ObjectDB 清理告警也出现在原先无 Mod 基线中；记录自有旧 Image 已被释放，但不宣称完成长时间内存验收。

建议正常从 Steam 启动新版后确认以下体验：

- [ ] 主菜单图库入口和 F10；首次启动能看到随附咖波图片，关闭再启用、选图、导入、热点设置、保存后重启。
- [ ] 选择处理后的动态图，调整“默认帧”并保存；右键按住循环、松开回选定帧，左键保持静态，重启保留。
- [ ] 地图画线/擦除、原右键/中键临时模式、F8/F9 和缩放。
- [ ] 慢速点击按钮中心和边缘，确认视觉作用点；拖牌、目标选择和其他特殊光标。
- [ ] 全屏/窗口、高 DPI、手柄切换、连续运行的流畅度。
- [x] 用户确认旧版与朋友联机正常。

工坊订阅安装检查在上传条目后进行：先将同 ID 的手动安装版备份到 mods 目录外，再订阅私密条目，检查加载日志、首次配置创建、更新后配置保留及取消订阅。保留手动副本会让同版本的工坊副本被禁用，不能据此判断工坊安装成功。

已测平台和分支仅限上述 Windows public-beta。GIF 使用 Windows GDI+；不与其他本地光标替换 Mod 混用。文件异常会回退原版，配置轮询每秒一次，只替换图片内容时需 F8。
