# 工坊更新发布工作区

作者：Toyer1209，Mod 版本 0.2.2；现有条目 ID：3819632370。保留 mod_id.txt，同一个上传命令更新原条目。当前 visibility=private。2026-10-14 已成功更新完整 0.2.2、128 张图库、封面和介绍。

本目录保存作者的工坊提交配置和条目 ID。完整可上传工作区位于 [0.2.2 工坊包](../releases/v0.2.2/CustomCursorLoader-v0.2.2-workshop.zip)，解压后得到 CustomCursorLoaderWorkshop/。

工坊包的 content/CustomCursorLoader/ 包含本 Mod DLL、Manifest、许可说明及 gallery/ 的 128 张去重咖波图片。图库共 9,253,715 字节（约 8.8 MiB），包括原图和处理成品，重复爪爪只保留一份；完整目录和 SHA-256 见 [图库清单](../docs/gallery-catalog.csv)。软件与原创默认箭头按 MIT 许可；角色素材不纳入项目的原创素材 MIT 授权范围。

玩家首次启动会自动把随附图片导入本地图库，按 F10 可直接选择。重复启动和更新按内容去重，不修改当前选图、默认帧、大小、热点或个人配置。

工坊包内的 image.png 是咖波主题封面，498295 字节，小于 1 MB；仓库预览见 [封面](../docs/images/cover.png)。

从 [Mega Crit 官方上传器](https://github.com/megacrit/sts2-mod-uploader/releases)下载 Windows x64 上传器。登录 Steam，在上传器所在目录打开 PowerShell，使用解压后的完整工作区路径：

```powershell
.\ModUploader.exe upload -w "你的解压目录\CustomCursorLoaderWorkshop"
```

作者更新现有条目时保留 mod_id.txt，使用同一工作区。其他作者创建自己的条目时按官方说明使用自己的配置和 ID。可见性保持现有 workshop.json 设置；若准备公开，将 visibility 改为 public 再上传。workshop.json 已省略 minBranch/maxBranch；保留这两个字段时曾反复在最终提交约 30 秒后超时，省略后的最小提交、完整介绍及原目录提交均成功。兼容分支按[官方说明](https://github.com/megacrit/sts2-mod-uploader/blob/main/template/README.md)在工坊网页核对；项目仍只声明已测 Windows public-beta。

订阅测试前关闭游戏，把同 ID 的手动安装版备份到 mods 扫描目录之外。确认工坊目录加载 0.2.2、首次启动有随附咖波图片、更新后个人配置保留。本次运行测试使用隔离副本与模拟输入，不等同完整 Steam 订阅验收。
